# Cats Can Dance

The home of electronic music in India, as four products that work alone and better together.

- **Cats Can Dance** (`apps/ccd`): the curated gig guide, going out with a crew, our Episodes and tickets.
- **Artists** (`apps/artists`, working name Headliner): sourced artist pages that keep themselves up to date, discovery, booking and tour dates.
- **Gate** (`apps/gate`): the host side. Put on a night, sell or list tickets, import tickets sold elsewhere, run the door from a phone, read the report.
- **School** (repo `paramminhas5/Ableton-Final-Next`, working name Ustad): learn production and DJing by making real music on a real instrument.

See `CLAUDE.md` for the layout and rules, and each app's own README.
